# Student Management System

A responsive student records dashboard built with HTML, CSS, Bootstrap, and vanilla JavaScript.

## Features

- Add, edit, and delete student records
- Search by name, ID, course, or email
- Filter records by course
- Required-field, email, ID-format, and duplicate-ID validation
- Browser localStorage persistence
- Responsive layout for desktop and mobile

## Run

Open [index.html](index.html) in a browser. No build step or server is required.
